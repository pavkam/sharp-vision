# SharpVision.FigletFonts third-party notices

## Official FIGlet fonts

The following fonts are copied byte-for-byte from
[`cmatsuoka/figlet`](https://github.com/cmatsuoka/figlet) commit
`202a0a8110650a943f1125f536b3bb455cf72ee1`:

`banner`, `big`, `block`, `bubble`, `digital`, `ivrit`, `lean`, `mini`,
`mnemonic`, `script`, `shadow`, `slant`, `small`, `smscript`, `smshadow`,
`smslant`, `standard`, and `term`.

The source repository distributes these files under BSD-3-Clause. The complete
license and copyright notice is packaged as `licenses/BSD-3-Clause.txt`. Notices
embedded in each `.flf` resource are preserved unchanged.
