# Modality Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add application-owned modal scopes that constrain routed input, focus,
pointer state, and capture while allowing a menu bar and every retained submenu
popup to share one modal plane.

**Architecture:** `Application.Modality` owns a LIFO `ModalScope` stack whose
disjoint roots define the active interaction plane. `Router`, `FocusManager`,
and `PointerManager` consult the same inherited `ModalityManager`; Popup,
Window, and Menu layer lifecycle conveniences over that primitive without
changing rendering ownership.

**Tech Stack:** .NET 10, C# 14, xUnit v3, Shouldly, Microsoft Testing Platform,
SharpVision retained controls, Markdown/Prettier/markdownlint.

- [ ] **Step 3: Implement the three core types**

Use these exact public signatures:

```csharp
public enum OutsideInteraction
{
    Ignore,
    Dismiss,
}

public sealed class ModalScope: IDisposable
{
    public event EventHandler? DismissRequested;
    public event EventHandler? Exited;
    public Control Root { get; }
    public OutsideInteraction OutsideInteraction { get; }
    public bool IsActive { get; internal set; }
    public void Include(Control root);
    public void Dispose();
}

public sealed class ModalityManager: IDisposable
{
    public ModalScope? Active { get; }
    public ModalScope Enter(
        Control root,
        OutsideInteraction outsideInteraction = OutsideInteraction.Ignore,
        Control? initialFocus = null);
    public void Dispose();
}
```

The internal constructor is
`ModalityManager(Control root, FocusManager focus, PointerManager pointer)`.
`ModalScope` retains a private insertion-ordered `List<Control>` beginning with
`Root`. Validate enum values, dispatcher affinity, same-tree membership,
visibility, enabled state, disposal, initial-focus membership, and pairwise
non-overlap before mutation. `Dispose` asks the manager to unwind from the
youngest entry through that scope and publishes `Exited` once per committed
exit.

Implement internal manager seams with stable names used by later tasks:

```csharp
internal bool Allows(Control? control);
internal Control? BoundaryFor(Control control);
internal int ActiveRootCount { get; }
internal Control ActiveRootAt(int index);
internal void Unavailable(Control subtree);
internal void RootDisposed();
internal void RequestDismiss();
```

Detect unavailability by ancestry: a primary root contained within the
unavailable subtree ends its scope and every younger scope. Remove an included
root contained within that subtree. Do not compare identity only.

```csharp
[Fact]
public async Task Pointer_WhenSiblingMainMenuItemIsSelected_ReusesOneModalScopeAsync()
{
    var fileMenu = new Menu { Orientation = Orientation.Vertical };
    fileMenu.Items.Add(new MenuItem { Content = new ControlText("Open") });
    var editMenu = new Menu { Orientation = Orientation.Vertical };
    editMenu.Items.Add(new MenuItem { Content = new ControlText("Copy") });
    var file = new MenuItem { Content = new ControlText("File"), Submenu = fileMenu };
    var edit = new MenuItem { Content = new ControlText("Edit"), Submenu = editMenu };
    var menu = new Menu { Orientation = Orientation.Horizontal };
    menu.Items.Add(file);
    menu.Items.Add(edit);
    await using var surface = await ComponentSurface.MountAsync(
        menu,
        new Size(30, 8),
        TestContext.Current.CancellationToken);
    var filePopup = OwnedTree.Find<Popup>(file).ShouldNotBeNull();
    var editPopup = OwnedTree.Find<Popup>(edit).ShouldNotBeNull();

    await surface.Pointer.ClickAsync(file);
    var scope = surface.Application.Modality.Active.ShouldNotBeNull();
    await surface.Pointer.MoveToAsync(edit);

    surface.Application.Modality.Active.ShouldBeSameAs(scope);
    filePopup.IsOpen.ShouldBeFalse();
    editPopup.IsOpen.ShouldBeTrue();
}
```
