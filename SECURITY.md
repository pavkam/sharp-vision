# Security policy

## Supported versions

Until SharpVision has a stable release line, only the current `main` branch is
supported for security fixes.

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/pavkam/sharp-vision/security/advisories/new).
Do not publish exploit details in an issue, discussion, pull request, or public
commit before maintainers have had a chance to investigate.

Include the affected commit or package version, a minimal reproduction, impact,
and any terminal, multiplexer, or platform details needed to assess the report.
Redact credentials, personal data, and sensitive terminal output.

Maintainers will acknowledge reports, coordinate a resolution, and agree on a
disclosure path with the reporter. We intentionally do not promise a fixed
response time; careful remediation beats a made-up stopwatch.
