# Support

Use the repository's issue forms for reproducible defects and feature proposals.
When GitHub Discussions is enabled, use it for usage questions and design
conversation that is not a defect or a concrete proposal.

For a potential vulnerability, do not open a public issue. Follow the private
process in the [security policy](SECURITY.md#reporting-a-vulnerability).

Good reports include the SharpVision commit or package version, operating
system, terminal emulator or multiplexer, exact reproduction, expected result,
actual result, and redacted diagnostics.
